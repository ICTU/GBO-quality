# Bijdragen aan GBO-quality

Dank voor je interesse in het bijdragen aan GBO-quality!

## Gedragscode

Door bij te dragen ga je akkoord met de [gedragscode](CODE_OF_CONDUCT.md),
gebaseerd op de [Contributor Covenant](https://www.contributor-covenant.org/).

## Hoe draag je bij?

### Issues

Heb je een fout gevonden, een vraag of een verbetervoorstel? Open een
[issue](https://github.com/ICTU/GBO-quality/issues).

### Pull requests

1. **Fork** deze repository (of maak een branch als je schrijfrechten hebt).
2. Maak een branch aan: `git checkout -b feature/mijn-wijziging`
3. Maak je wijzigingen en commit met een beschrijvende boodschap.
4. Push je branch en open een **pull request** naar `main`.
5. Een beheerder beoordeelt je pull request.

## Commit-boodschappen

We volgen [Conventional Commits](https://www.conventionalcommits.org/nl/v1.0.0/):
`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`.

## GitHub Actions

Wie een workflow toevoegt, pint elke action op een volledige commit-SHA (en niet
op een tag of branch), conform de [ICTU GitHub policy](https://github.com/ICTU/github-policy).

## Hulp nodig?

Neem contact op met de repository-eigenaar (zie [README.md](README.md#contact)).
